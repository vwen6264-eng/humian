# 摸鱼大师 · 湖面工作台

在 Obsidian 桌面端使用的沉浸式动态湖面工作台。当前仓库包含插件运行代码与必要资源；插件 ID 为 `immersive-workbench`，不是整个个人知识库的备份。

## 页面与功能

- **湖心**：动态湖面、鱼与乌龟、定制与档案、投食和互动、音乐播放器。生物外观出生后固定，可改名，记录吃食；可休息、回到湖中或放生。
- **朝夕**：面向用户的日常安排与个人备忘，与 Agent 任务项目分开。
- **百艺**：浏览本地技能库；任务可关联技能，供 Agent 读取使用。
- **知屿**：知识导航与关联笔记。
- **拾光**：旅行地点、地球浏览、旅行照片和城市档案。
- **灵犀**：电影、电视剧、图书和动画收藏，集成豆瓣连接及其他搜索入口，使用简体中文界面。
- **任务**：项目管理、独立 Markdown 任务、拖拽看板、执行记录、人工验收和 Agent 接口。

界面采用通透湖面设计、站酷快乐体及紧凑响应式排版。主要交互窗口支持移动，部分窗口支持调整大小。顶部导航采用玻璃 Dock、首页分隔与选中标记。

## 安装

要求：Obsidian 桌面端，版本不低于 `manifest.json` 中的要求（目前为 1.8.7），设备支持 WebGL。

1. 下载本仓库 ZIP 并解压。
2. 把仓库内容放入 `<Vault>/.obsidian/plugins/immersive-workbench/`，确保 `manifest.json`、`main.js`、`styles.css` 与 `assets/` 位于该目录内，不要多套一层文件夹。
3. 在 Obsidian 的第三方插件中刷新并启用「摸鱼大师」，在命令面板搜索该插件提供的打开工作台命令。

插件包含多份运行模块与较大湖面资源，**不能只复制 main.js、manifest.json、styles.css 三个文件**。

## 升级：保留个人数据

先备份当前 Vault，再停用插件，覆盖运行代码与资源，最后重新启用。已有安装请保留原有的数据文件，尤其不要用仓库的初始配置覆盖个人配置。

保留内容包括：

- 插件根目录的 `data.json`、`pond.json`、`pond-play.json`、`glass.json`、`music-position.json` 及自己的恢复备份。
- `lingxi/data.json`、`lingxi/douban-data.json`：仓库仅提供无账号凭据的初始配置，已有用户应保留本地版本。
- Vault 中的任务、项目、收藏笔记、封面与旅行照片。
- 音乐播放器浏览器存储中的播放列表、本地导入和离线缓存。

仓库未包含个人生物档案、吃食记录、旅行记录、Agent 令牌、个人笔记、Cookie 或浏览器缓存。首次安装会使用默认值；个人数据不会因下载仓库而自动恢复。

## Agent 任务流程

任务与项目使用 Vault 内独立 Markdown 文件；看板和 Agent 读取同一份数据。任务拥有稳定 ID、版本和 ETag。

`backlog → todo → in_progress → in_review → done`

还支持 `blocked`、`canceled`。`backlog` 不自动执行；Agent 完成后提交 `in_review`，只有用户验收可进入 `done`。领取与更新校验版本和归属，发生冲突需重新读取，不能直接覆盖。

使用 `taskboard-cli.cjs` 调用正在运行的 Obsidian 插件接口，需要 Node.js 与可用的 Obsidian CLI。详情见 [任务接口说明](TASKBOARD.md)。

## 数据、安全与限制

- 不上传或依赖作者的本机路径，用户自行配置技能根目录、项目代码目录与收藏连接。
- 项目代码目录是领取校验与工作指令，**不是操作系统沙箱**。
- 关联技能后 Agent 需读取当前技能内容，接口记录读取来源；勾选技能不代表自动执行其中脚本。
- 退回修改可返回已绑定的 Claudian 对话；该适配依赖其内部接口，可能随版本变化。
- **WorkBuddy 桌面原对话暂不支持自动通知**，需要复制修改意见手动发送；不能将打开应用视为已执行任务。
- 豆瓣等联网资源、音乐搜索、地图瓦片取决于外部服务、登录与网络条件；离线不保证这些功能可用。
- 地球地图、高清湖面与预览会使用 GPU，低配置设备可能需要缩小窗口或减少同时打开的动态页面。
- 本次发布不包含独立的「银河星球」插件。
