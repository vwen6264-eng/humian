# 湖面沉浸式工作台

Obsidian 插件最终版，提供动态湖面首页、日程与备忘、技能库、Wiki 知识库和旅行地图模块。

## 安装

将此目录复制到 Obsidian Vault 的 `.obsidian/plugins/immersive-workbench/`，在 Obsidian 的社区插件设置中启用“湖面”。

插件运行数据（`data.json`）由本地 Obsidian 自动生成，不包含在仓库中，避免提交个人路径和工作区数据。

## 目录

- `main.js`：插件主逻辑
- `planner.js`：日程与项目功能
- `styles.css`：统一湖面视觉样式
- `assets/`：湖面背景、Cubes 动效及旅行地图资源
